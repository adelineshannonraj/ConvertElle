# ConvertElle — Modular Luxury Fashion
> *"One Garment. Endless You."*

**ConvertElle** is a revolutionary modular luxury fashion platform bridging executive daytime ready-to-wear with museum-grade haute couture. Through patented concealed magnetic docking hubs, a single crease-resistant garment converts in 30 seconds into sovereign red-carpet silhouettes.

---

## ✨ Features & Architecture

### 1. FAUNA Capsule Collection — *The Animal Within*
Six animal archetypes translating nature's blueprints into wearable architectural couture:
- 🦋 **The Butterfly (*Papilio Metamorphosis*)** — Shimmering gold microsequin column dress converting into millinery wire glitter silk organza wings.
- 🦚 **The Peacock (*Pavo Cristatus*)** — Royal blue satin corset & fluid violet trousers elevating into a 120-eyelet cruelty-free organza plumage ballgown.
- 🐅 **The Tiger (*Panthera Tigris*)** — Executive black sheath & slate-blue tuxedo blazer elevated with cast brass tiger shoulder armor and segmented maroon velvet bell sleeves.
- 🦢 **The Swan (*Cygnus Olor*)** — Modern Muse raw denim & halter top transforming via 3D hand-carved crystal swan peplum and cruelty-free plume bell cuffs.
- 🐆 **The Leopard (*Panthera Pardus*)** — "The Column" high-neck sheer knit & leopard jacquard pencil skirt converting into an architectural high-collar cape or tiered petal ballgown.
- 🪼 **The Jellyfish (*Aurelia Etherea*)** — Slate tailored trousers & pink bustier transforming with frosted tulle bolero and sovereign bioluminescent floating umbrella dome gown.

### 2. Commercial 4-Tier System
Customers configure each garment with precision transparent pricing:
1. **The Base Garment** — Executive daytime foundation ($680)
2. **Base + Expression Kit** — Day-to-dinner transition ($1,120 – $1,200)
3. **Base + Statement Kit** — Evening cocktail transformation ($1,830 – $2,120)
4. **The Full Haute Couture Suite** — Complete gala red-carpet metamorphosis ($3,550 – $4,320)
5. **Kits Only** — Modular capsules for existing base owners ($1,650 – $2,200)

### 3. Interactive Atelier & E-Commerce
- **Live Lookbook Switcher**: Instant tier-to-photo intelligence showing real garment photography.
- **Dynamic Garment Builder**: 4-stage visual silhouette builder.
- **Bespoke Fit Consultation Modal**: Private salon measurement booking.
- **Interactive Shopping Bag**: Cart drawer with tier breakdown and lifetime alteration guarantees.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/adelineshannonraj/ConvertElle.git

# Navigate to project directory
cd ConvertElle

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:5173` in your browser.

### Production Build

```bash
# Build optimized production bundle
npm run build

# Preview production build locally
npm run preview
```
